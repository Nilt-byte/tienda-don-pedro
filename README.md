# 🛒 Tienda Don Pedro

Tienda de barrio ubicada en Itagüí, dedicada a la venta de productos básicos. Este proyecto permite organizar los productos y sus precios, registrar clientes y llevar un control sencillo del inventario mediante Python.

## 📦 Productos

| Producto | Precio |
|---|---:|
| Leche 1L | $4.500 |
| Pan tajado | $6.500 |
| Huevos x12 | $14.000 |
| Café 500g | $18.000 |
| Panela | $3.500 |
| Arroz 1kg | $4.500 |

## 🛵 Domicilios

La Tienda Don Pedro ofrece servicio de domicilios en el barrio **Santa María, Itagüí**.

- **Horario:** lunes a sábado, de 8:00 a. m. a 7:00 p. m.
- **Cobertura:** barrio Santa María y sus alrededores.
- **Pedido mínimo:** $10.000 COP.
- **Tiempo estimado de entrega:** 30 a 45 minutos.

## 📁 Estructura del proyecto

```text
tienda-don-pedro/
├── datos/
│   ├── productos.txt
│   ├── clientes.txt
│   └── ventas.txt
├── src/
│   └── main.py
├── .gitignore
└── README.md
```

## 🚀 Cómo ejecutarlo

Debes tener Python instalado. Ejecuta el siguiente comando desde la carpeta principal del proyecto:

```bash
py src/main.py
```

El programa muestra la lista de productos, la cantidad total y el valor del inventario.
